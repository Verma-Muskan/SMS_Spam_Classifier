# SMS_Spam_Classifier
Tool to classify whether it is a spam SMS or not. Built  using Multinomial Naive-Bayes Algorithm
## Overview

The SMS Spam Classifier is a machine learning project designed to identify and classify SMS messages as either "spam" or "ham" (non-spam). This tool can be used to filter out unwanted spam messages from a dataset of SMS texts.

## Features

- **Data Preprocessing:** Cleans and prepares SMS data for training and testing.
- **Machine Learning Model:** Utilizes machine learning algorithms like Naive Bayes, SVM, or Logistic Regression for classification.
- **Evaluation Metrics:** Provides accuracy, precision, recall, and F1-score for model performance evaluation.
- **Interactive Interface:** Includes a simple command-line or web-based interface to classify new SMS messages.
